## 1. 결정적 판별 신호 — `vtol_vehicle_status.vehicle_vtol_state`

천이 성공/실패는 이 한 채널로 즉시 갈린다. **4(FW)가 찍히는가.**

| | 성공 (SITL A1) | 성공 (SITL A2) | **오늘 실기체** |
|---|---|---|---|
| 전이열 | `[3, 1, 4, 2, 3]` | `[3, 1, 4, 2, 3]` | **`[3, 1, 3]`** |
| TRANS_TO_FW(1) 체류 | **2.556 s** | **2.500 s** | **11.10 s** |
| FW(4) 도달 | ✅ 19.04 s 체류 | ✅ 19.39 s 체류 | ❌ **한 번도 없음** |
| TRANS_TO_MC(2) = 역천이 | ✅ 5.14 s | ✅ 5.32 s | ❌ **없음** |
| `forward_ok_3_1_4` | True | True | **False** |
| 종료 | quad-chute 없음 | quad-chute 없음 | **Quad-chute → 3 으로 복귀, `fixed_wing_system_failure=1` 래치** |

**육안대조 요령:** 성공은 1(TRANS_TO_FW)에 **2.5초**만 머물고 4로 넘어간다.
1에 5초 이상 머물면 이미 실패 궤도다. 오늘은 11.1초 머물다 3으로 되돌아갔다.
그리고 `2`(TRANS_TO_MC)가 로그에 없으면 **역천이는 일어나지 않은 것**이다 —
오늘 "역천이처럼 보인 것"은 quad-chute 로 인한 MC 강제 복귀다.
