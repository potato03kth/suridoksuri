# 피토 영점 열드리프트 실험 — 오케스트레이션

## 0. 먼저, 두 가지 오해를 걷어낸다

**① "재캘리브레이션"은 실험이 아니다.**
캘리브레이션은 `SENS_DPRES_OFF` 라는 **파라미터를 덮어쓰는 행위**일 뿐, 아무것도 측정하지 않는다.
지금 재캘하면 영점이 맞춰질 뿐 "왜 틀어졌는지"는 여전히 모른다.
**측정해야 할 것은 `differential_pressure.differential_pressure_pa`(원시값)가
`differential_pressure.temperature`(센서 자체 온도)에 따라 어떻게 움직이는가다.**
→ **실험 중에는 캘리브레이션을 하지 않는다.** 파라미터를 고정한 채 원시값만 기록한다.

**② 온도계는 이미 있다.**
센서가 자기 다이 온도를 `differential_pressure.temperature` 로 보고한다 —
`logs/2026-07-30_review.md` §7-4 의 회귀도 이 값을 쓴 것이지 외부 온도계를 쓴 게 아니다.
**에어컨 설정온도와 기상청 기온은 "온도를 재기 위한 것"이 아니라
①센서의 온도 채널이 믿을 만한지 교차검증하고 ②온도 범위를 만들기 위한 것**이다.

---

## 1. 무엇을 가르려 하는가

`logs/2026-07-30_review.md` §7-9 기준, **확실한 것**은 이것뿐이다:

```
원시 영점  −29.0 ± 1.2 Pa  (07-25/26/28/29, 4개 날짜)
        →  −44.7 ± 0.5 Pa  (07-30, 8개 로그)
        =  15.7 Pa 이동 (날짜간 산포의 13배)
```

**미입증:** 그 원인. 경쟁 가설 셋 —

| | 가설 | 예측 |
|---|---|---|
| **T** | 센서 열드리프트 | 원시 영점이 온도에 **연속·가역적**으로 −1.5~−2.2 Pa/°C 로 따라간다 |
| **W** | 결로/수분 (냉방 차량 → 습한 옥외) | 온도 상관은 약하고, **승온·강온 경로가 갈린다(히스테리시스)**, 시간지연 있음 |
| **M** | 배관 꺾임·재체결 (이송 중) | 온도와 무관, 계단형 1회성. 이후 값이 그대로 유지 |

**이 실험은 T 를 직접 측정해 기각 또는 채택한다.** W 는 Phase 3 로 재현을 시도하고,
M 은 Phase 1 의 현재 영점 위치로 간접 판별한다.

> ⚠️ **셋 다 "현장 주변온도에서 열평형 후 캘 + 캘 직후 정지 CAS≈0 검증"이라는 조치는 동일하다.**
> 이 실험의 가치는 조치를 바꾸는 데 있는 게 아니라, **이 피토를 천이 게이트로 계속 믿을 수
> 있는지**(H18 조치 ④: 대지속도/개루프 천이 전환, 센서 교체 여부)를 결정하는 데 있다.

## 2. 왜 지금 할 만한가 — 검정력

지금 데이터의 결함은 **온도 폭이 2~3 °C 뿐**이라 기대신호(4~6 Pa)가 잡음(±9~18 Pa)에
묻힌다는 것이다. 실측 잡음(지상 정지 sd ≈ 2.7 Pa, 1-lag 자기상관 ≈ 0, 1.0 Hz)으로
보수적으로(sd 10 Pa, 유효표본 30 % 가정) 계산하면:

| 온도 폭 ΔT | 로깅 시간 | 기울기 95% CI 폭 |
|---|---|---|
| 10 °C | 30분 | ±0.29 Pa/°C |
| **15 °C** | **30분** | **±0.20 Pa/°C** |
| 15 °C | 60분 | ±0.14 Pa/°C |
| 20 °C | 60분 | ±0.10 Pa/°C |

**현재 데이터의 CI 폭이 ±3~5 였다. 30~50배 개선이고, 0 과 −1.9 를 가르는 데 압도적으로 충분하다.**
비행 불필요, 90분, 소모품 0. **할 만하다.**

## 3. 사전 등록 판정 기준 (실험 전에 고정 — 나중에 바꾸지 않는다)

전 구간 회귀 `raw = a + b·T` 의 기울기 `b` 와 그 95% CI 로 판정한다.

| 결과 | 판정 | 후속 |
|---|---|---|
| CI 가 **[−2.5, −1.3] 안에 들어감** | **T 채택** — 열드리프트가 원인 | 07-30 의 15.7 Pa 가 설명됨. 조치는 "현장 열평형 캘 + 검증"으로 충분 |
| CI 가 **0 을 포함하고 −1.3 을 제외** | **T 기각** — 열드리프트 아님 | 15.7 Pa 는 W 또는 M. **피토를 천이 게이트에서 빼는 쪽으로 기운다** |
| CI 가 **−1.3 도 0 도 제외** (예: −0.8±0.2) | **부분** — 열계수는 있으나 15.7 Pa 를 다 설명 못 함 | 남는 몫만큼 W/M 병존. Phase 3 결과와 합쳐 판단 |
| CI 폭이 ±0.5 초과 | **실험 실패** — 온도 폭 부족 또는 기류 혼입 | §5 검증항목 확인 후 재실시 |

**추가 판정 (Phase 2 양방향):**
- 승온 기울기와 강온 기울기가 CI 내에서 일치 → **T 지지**
- 두 기울기가 유의하게 다르거나 raw–T 궤적이 **고리(loop)** 를 그림 → **W 지지(히스테리시스)**
- raw 가 온도 방향과 무관하게 **시간에 따라 단조** 이동 → 전자부 워밍업 드리프트 또는 누설. T 기각

## 6. 분석

ulog 를 `logs/2026-07-31_pitot_thermal/` 에 넣고:

```python
import numpy as np
from scipy import stats
from pyulog import ULog
ul = ULog('logs/2026-07-31_pitot_thermal/<파일>.ulg'); t0 = ul.start_timestamp
dp = [x for x in ul.data_list if x.name == 'differential_pressure'][0]
t  = (dp.data['timestamp'] - t0) / 1e6
raw = np.asarray(dp.data['differential_pressure_pa'], float)
T   = np.asarray(dp.data['temperature'], float)

r = stats.linregress(T, raw); tc = stats.t.ppf(0.975, len(T)-2)
print(f"전체   b = {r.slope:+.3f}  95%CI [{r.slope-tc*r.stderr:+.3f}, {r.slope+tc*r.stderr:+.3f}]  r²={r.rvalue**2:.3f}")

# ★양방향 분리 — 시간 vs 온도 교락 판별
dT = np.gradient(T, t); up, dn = dT > 0.002, dT < -0.002
for lab, m in [('승온', up), ('강온', dn)]:
    if m.sum() > 30:
        rr = stats.linregress(T[m], raw[m]); tt = stats.t.ppf(0.975, m.sum()-2)
        print(f"{lab}  b = {rr.slope:+.3f}  95%CI [{rr.slope-tt*rr.stderr:+.3f}, {rr.slope+tt*rr.stderr:+.3f}]  n={m.sum()}")

# ★시간 단조드리프트 검정 (온도를 통제한 뒤 시간이 남는가)
A = np.vstack([np.ones_like(T), T, t]).T
coef, *_ = np.linalg.lstsq(A, raw, rcond=None)
print(f"raw ~ 1 + T + t  →  b_T = {coef[1]:+.3f} Pa/°C,  b_t = {coef[2]*3600:+.2f} Pa/시간")
```

`b_t` 가 유의하게 0 이 아니면 시간 드리프트(누설·워밍업)가 섞여 있는 것이므로
단순 `raw~T` 기울기를 그대로 믿으면 안 된다.
