## S04 — [HW] 설계 방법론: 해석 기반 최적해 탐색

**부제:** 감이 아니라 수치로 형상을 골랐다

- **자체 개발 스프레드시트 계산기 3종**을 축으로 설계 전 과정을 정량화
  - `프로펠러` 시트 — 유동속도에 따른 추력·효율 저하 정량화. Tarot 4114(320kv)·EM3115(900kv)
    공식 데이터로 정지추력/파워계수 보정, Apps Script로 **가변 RPM 자동 산출** → **추력·소비전력 10% 오차 내 예측**
  - `계산기` 시트 — 주익 제원 입력 시 12개 레이놀즈 수 × 속도별 공력 자동 연산
    (**공력 371 · 푸셔 성능 144 · 중량 60개 데이터 종합**)
  - `에너지` 시트 — 주익 크기 변화에 따른 중량 변동 반영, 임무 제약 하 소비 전력량 산출
- **외부 해석 도구와 연동:** XFLR5(공력·정적/동적 안정성) + ANSYS(1-way FSI·fluent·modal·harmonic)
- 그림: 전체 해석 다이어그램 (1차 보고서 3-1)

> 💡 **이 장의 메시지:** "설계 → 해석 → 재설계"를 사람 손이 아니라 **자동화된 계산 파이프라인**으로 돌렸다.

## S05 — [HW] 주익·에어포일 최적해 도출

**부제:** 60개 형상 조합 전수 평가

- Apps Script로 **루트시위 6종 × 윙스팬 10종 = 60개 조합** 공력 데이터 자동 연산
- 평가지표: 최대 전비 순항속도 / 실속속도 / 임무별 소비 전력량
  → **Min-Max 정규화 + 대회 배점표 가중치 합산 → 100점 환산**
- **제약조건을 명시적으로 걸었다:** 배터리 70% 방전한계(170Wh) 초과 형상 배제,
  AR ≥ 10 형상은 '카본파이프 + ASA AERO' 플랫폼의 구조적 강성 한계로 보류
- 에어포일 최종 순위: **NACA2412** > SD7037 > RG15 > DAE12 > MH32 > NACA4412 > SG6043
- **설계 실효성 보정:** 이론적 최대 양항비 지점이 아니라, 푸셔 모터 과부하·추진효율 저하를 반영한
  **'최대 전비 속도'(km/kWh)** 를 기준으로 삼아 실제 항속거리를 보장
- 검증 결과: 총 소비 전력량이 **6S 10000mAh의 80% 가용량(192Wh)을 안정적으로 하회**
- 그림: 조합별 점수표 / 에어포일 순위표

## S06 — [HW] 안정성 설계: V-tail & 스톨 방지

**부제:** FC 제어에 기대지 않는 기체 고유 안정성

- **V-tail 사이징** — WP 통과오차 최소화를 위해, FC 제어가 있음에도 **동적 안정성이 보장되는
  최소 크기·CG 모멘트암**을 6개 후보군 중에서 정량 선정
- **에일러론 스톨 방지** — elliptical 날개 + **팁 음의 incidence angle**
  - 검증(20 m/s, AoA 10°): 루트 부근은 뒷전 박리 시작, **팁 부근은 유효 받음각 감소로 박리 지연 →
    층류 유지** ⇒ 에일러론이 살아 있는 상태로 스톨 진입
- 그림: 스팬 위치별 국부 양력계수 / 주익 압력분포 / speed contour

> 💡 **메시지:** "제어가 잡아주니까"가 아니라 **기체 자체가 안 넘어가게** 설계했다.

## S07 — [HW] 구조·진동 해석 검증

**부제:** 최악 하중 조건에서의 안전계수·공진 회피

- 해석 조건 = **기체가 마주할 수 있는 가장 가혹한 환경**
  - 최고속도 **80 km/h** · 최대받음각 **15°** · 최대추력 **쿼드 12 kgf / 푸셔 4 kgf**
- 재료 모델링: 카본파이프 → CFRP, ASA AERO → 발포·저 infill 반영해 영률·포아송비 조정
- 구조해석: fluent 공력하중 + 모터 추력 → static structural
  → **두 재질 모두 가혹 조건에서 충분한 안전계수 확보**
- 진동해석: **모드 20개**, 블레이드 통과 주파수(BPF)로 회피 주파수 대역 산정
  → 유효질량비 5% 초과 & 회피대역 내 위험 모드 **4·5번** 식별, harmonic response 위상·진폭으로 재확인
- **한계도 그대로 보고:** ANSYS student 메시 제한으로 2-way FSI 대신 1-way FSI 수행.
  위험 모드가 뜬 원인은 **팁 카본파이프 지오메트리 메싱 에러로 누락**돼 ASA AERO가 하중을 전담한 결과 —
  설계대로 재해석 시 공진 주파수가 상승해 회피대역을 벗어날 것으로 예상 (재해석 예정)

> 💡 한계를 먼저 밝히면 질의응답에서 방어가 아니라 설명이 된다.

## S08 — [HW] 제작 및 실물 검증

**부제:** 설계안이 아니라 날아다니는 기체

- **수리1호 제작 완료** — 3D 프린팅 기반 자체 제작
  - 재료 선정 근거: 후보(PLA / LW-PLA / PETG / ASA / ASA-CF / ASA AERO) 중
    **ASA AERO**(유리전이 95 °C ≫ LW-PLA 55 °C, UV 저항·인성 우수, PLA 밀도 절반)
  - 역할 분담: **카본파이프 + 일반 ASA = 구조 하중 / ASA AERO = 비구조부 경량화**
  - 25% 정렬 elliptical wing의 복잡 형상 구현에 3D 프린팅이 최적이라 판단
- **완료된 실물 검증:** Dual M10 GPS 기반 **호버링 시험 완료**, 랜딩기어 retraction 동작, V-tail 조립
- 사진: 호버링 / 조립 / 랜딩기어 retraction / V-tail
- 🔴 **[빈칸] 실측 제원표** — MTOW, 익폭, 전장, 공허중량, 배터리 사양

## S11 — 안전장치 구현 상황

**부제:** 물리 · 비행제어 · 소프트웨어 3중 안전망

**① 물리 안전장치**
- **CO2 카트리지 격발 낙하산** — 화약식 대비 즉각적 기계 사출로 전개 시점을 앞당김.
  저고도 자유낙하 상황에서 신속히 유효 항력 형성 → 충격 에너지 격감

**② 비행제어 안전 알고리즘**
- **복귀 가능 에너지 동적 산출** — 단순 잔량(%) 페일세이프에서 탈피.
  MC 기동전력 1000 W + FW 순항(70 km/h, 전비 400 m/Wh) 기반으로 **실시간 귀환 요구 에너지**를 계산,
  6S 10000mAh의 20% 안전마진 도달 즉시 RTL
- **비상 활공 천이(글라이딩)** — MC 구동계 고장으로 자세제어 불가 시, 자세를 억지로 잡는 대신
  **의도적 급강하로 위치E→운동E 전환 → 실속속도 확보 → FW 천이 → 푸셔 최대추력 상승 → 귀환·활공착륙**

**③ 소프트웨어 안전망 (실비행에서 실제 발동)**
- RC 모드스위치 + ROS 토픽 **이중 오버라이드** → 실패 시 AUTO.LOITER 폴백
- **조종사 인계 감지 시 자율노드 자동 정지** (실비행 사고 대응으로 신설)
- 상태별 **탈출 타임아웃 4종** + **이륙지점 기준 거리상한 300 m** (마지막 기하학적 제동장치)

## S12 — 유도·제어·항법 아키텍처

## S13 — 경로생성: eta³ Clothoid

- 그림: `fc_bridge/run_phase1.py --dry-run --plot` 6패널 / planner 비교 시각화

## S15 — 검증 체계: 3단 검증 피라미드 ★

**부제:** 검증을 통과하지 못한 코드는 기체에 올라가지 않는다

```
[3층]  실기체 비행     59회분 로그 · ulog 79건 전량 자동 분석
  ↑ 통과해야 올라감
[2층]  SITL 회귀       시나리오 24런 자동 실행 · 자동 판정
  ↑ 통과해야 올라감
[1층]  단위 테스트     1,811건 (비행제어 783 + 객체인식 1,028), ROS 없이 실행
```

- **구조가 검증을 가능하게 했다** — 비행 로직을 ROS 비의존 순수함수로 뽑았기 때문에 1층이 성립
- SITL 성과 1건 깊게: **PX4 상류 회귀 버그를 소스 계보까지 추적해 2줄 패치로 해소**
  - 북향이탈 **21.78 → 0.38 m** / 고도편차 판정 **FAIL → PASS** / 회귀 **0건**
- 비행 로그는 매 비행 전량 회수 → 자동 진단서 생성 → 결함 규명 → 수정 → 재배포

> 💡 발표에서 시간 배분을 가장 크게 줄 장. 질의응답 방어력도 여기서 나온다.

## S19 — [SW] 객체인식 및 정밀착륙

**부제:** 결정론적 고전 CV + 상대 pose 폐루프

- **고전 CV(OpenCV) 채택 근거:** 결정론 = 신뢰도 / RPi5 경량 / 학습 데이터셋 부담 0
  → 대회 당일 "오작동·오인식 절대 불가" 요구에 정면 대응
- **coarse → fine 2단 검출** — 고고도에서 소형 피처는 원리적으로 디코드 불가(GSD 표로 제시)
  ⇒ fine 락·검증 전에는 착륙 커밋 금지 (커밋 게이트가 코드 구조로 강제됨)
- **30 cm 정밀도는 폐루프로만** — GPS 절대좌표는 1~2 m가 하한
  → 카메라가 제어오차를 직접 측정하는 비주얼 서보잉
- 실측: 프레임당 **18 ms**, solvePnP 거리오차 **0.25~0.58 %**
- 착륙점은 **기체 최외곽 반경 기반 안전창**에서 산출 (물리 치수 반영, 매트 이탈 차단)
- 그림: 검출 오버레이 / GSD 표 / 데이터 흐름도
