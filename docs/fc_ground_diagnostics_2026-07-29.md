## 1. 자기계 — **세기(|B|)의 헤딩 의존을 지상에서 검출**

### 1-1. 측정 조건과 그 한계

실내(사용자 자택)에서 기체를 수평 바닥에 놓고 기수만 바꿔가며 측정했다.
**GPS 미획득 상태**라 아래가 성립하지 않는다:

```
mag_strength_ref_gs:     nan      <- WMM 기준값 없음
mag_inclination_ref_deg: nan
xy_valid: False
```

⇒ **`test_ratio` / `field_disturbed` 검사는 채점 자체가 돌지 않는다.**
`pre_flt_fail_mag_field_disturbed: False` 가 뜨는 것은 "합격"이 아니라 **"채점 안 함"** 이다.
이 절의 판정은 전부 **참조값 없이도 성립하는 자체 일관성**(같은 장소에서 방향만 바꿨을 때
변하면 안 되는 양이 변했는가)에만 근거한다.

### 1-2. 측정 원본 (5회)

| 회차 | 기수 (EKF yaw) | `mag_inclination_deg` | `mag_strength_gs` | innovation `heading` | 상태 |
|---|---|---|---|---|---|
| A | +27.5° | 56.18 / 56.88 | 0.400 / 0.402 | 0.00029 / 0.00024 | RPi5 재부팅 15분 후, **EKF 미수렴** |
| B | −155° | 47.51 / 47.17 | 0.415 / 0.413 | 0.0127 / 0.0206 | **미수렴 잔여** |
| A′ | +33.2° | 52.13 / 52.22 | 0.425 / 0.424 | 0.0073 | |
| **A″** | **+33.4°** | **51.90 / 52.37** | **0.4213 / 0.4209** | — | **정지·수렴 완료** |
| **B′** | **−153.1°** | **52.37 / 52.17** | **0.37915** | 0.00096 / 0.00117 | **7분 안정 후** |

(두 값은 EKF2 인스턴스 0/1. 자세는 A″ `Roll 4.0° Pitch −0.5°`, B′ `Roll 3.8° Pitch −1.2°`.)

**유효한 비교는 A″ vs B′ 뿐이다** — 둘 다 수렴 완료·같은 장소·같은 시간대.

### 1-3. 🔴 확인된 것 — 세기가 방향에 따라 10% 변한다

| 기수 | `mag_strength_gs` | 광주 지자기(0.503 G) 대비 |
|---|---|---|
| 북동 +33.4° | **0.4213** | 83.8 % |
| 남서 −153.1° | **0.3792** | **75.4 %** |
| **차이** | **−0.042 G (−10.0 %)** | |

**자기장 세기 \|B\| 는 캘리브레이션이 완전하면 방향과 무관한 상수여야 한다.**
10% 변동은 hard-iron/soft-iron 보정이 불완전하다는 직접 증거다.
`CAL_MAG0_ODIAG` 최대 0.0959(정상 ±0.05 초과)와 정합한다.

**이것이 왜 결정적인가 — `EKF2_MAG_CHK_STR = 0.2`(±20%, 하한 80%):**

- 북동 83.8 % → 통과
- 남서 **75.4 % → 탈락**

지금 실내에서 이 검사가 안 걸리는 이유는 오직 `ref = nan`(§1-1) 때문이다.
**야외에서 GPS 를 잡으면 이 검사가 살아나고, 남쪽 계열 헤딩에서 자기계가 기각된다.**

이는 `5d55b3f` 의 "헤딩 의존 `test_ratio`"(−45~0°에서 0.06 / −180~−135°에서 4.18~6.69)와
`655f539` 의 원 증상("적용 후 0.344 G = 기준의 68%, `EKF2_MAG_CHK_STR` 탈락")을 잇는
**메커니즘 특정**이다: **남쪽 계열 헤딩에서 \|B\| 가 임계 아래로 떨어져 EKF 가 자기계를 버린다.**

### 1-4. ❌ 기각된 가설 — "복각(inclination) 스윙"

측정 A·B 만 보고 **"복각이 56.5° → 47.3° 로 9.4° 스윙한다 = 방향 의존의 직접 증거"** 라고
판단했으나 **틀렸다.** 수렴 완료 후 재측정(A″ 52.1° / B′ 52.3°)에서 **복각은 방향과 무관하게
일정**했다. A 의 56.5°·B 의 47.3° 는 **RPi5 재부팅 직후 EKF 미수렴 아티팩트**였다.

같은 이유로 innovation `heading` 도 B(0.0127~0.0206) → B′(0.00096~0.00117) 로 1/13 이 됐다.

> **교훈:** 재부팅·전원 재인가 후에는 EKF 수렴을 기다리고 측정한다. 판정 지표가
> **방향을 되돌렸을 때 원래 값으로 복귀하는지**(A→B→A)로 반드시 교차확인한다.
> 이번엔 A→B→A′ 에서 A 로 복귀하지 않은 것이 미수렴을 드러냈다.

### 1-5. 남은 한계 — 실내에서는 여기까지다

**기체 자체 왜곡과 외부 환경 왜곡을 분리할 수 없다.** 기수를 돌리면 주변 물체(측정 시
전방에 PC 가 있었음)와의 상대 방위도 함께 바뀐다. 캘리브레이션은 기체에 고정된 금속만
보정하며 외부 물체는 보정 대상이 아니다. 위치 이동은 10~15 cm(벽에서 떨어진 지점, 사용자 확인).

부수 관찰:
- 사용자는 동체 기수가 약 −1.91° 처져 있다고 보고했으나 EKF 실측 자세는
  `Pitch −0.5° / −1.2°`, 오히려 `Roll 4.0° / 3.8°` 였다. 레벨 캘리 오프셋은
  `SENS_BOARD_X_OFF −2.26°`(롤) / `Y_OFF −0.54°`(피치). **기체 프레임 기준 수평과
  센서 보드 기준 수평이 어긋나 있을 가능성**이 있으나 이번 진단 범위 밖이다.
  정지 상태에서 EKF 는 가속도계로 자세를 알고 자기장을 그 자세로 변환하므로,
  이 기울기 자체가 \|B\| 를 바꾸지는 않는다.
- `CAL_MAG1_PRIO = 0` — 보조 자기계 비활성. 교차검증이 꺼져 있다.
- `EKF2_MAG_CHK_INC = 20.0`(±20°)로 복각 검사는 관대해 이번 값들은 전부 통과권.
- `EKF2_MAG_DECL = −8.15°`, `EKF2_DECL_TYPE = 3` — 한국 편각과 정합.

### 1-6. 야외에서 확정할 항목 (미수행)

GPS 3D fix 상태에서만 가능하다. **위치를 고정한 채**(바닥 표식 사용, 벽 등 기준물로
각도를 만들면 위치가 함께 변한다) 제자리 회전으로 4방위 측정:

1. `mag_strength_gs` 의 **방향 간 편차** — 이번 지상 실측의 10% 가 야외에서도 재현되는가
2. `mag_strength_ref_gs` / `mag_inclination_ref_deg` — 이때는 `nan` 이 아니므로 **절대 판정** 가능
3. `test_ratio` 실채점 — **합격선: 남쪽 계열 헤딩에서 `test_ratio < 1`**

측정 전 **GPS fix 후 2분 정차**로 EKF 수렴을 확보할 것(§1-4).

## 2. pusher 추력 미발생 — **물리 점검 미수행**

### 2-1. ⚠️ 이 절의 상태

**2026-07-29 현재 물리 점검은 수행되지 않았고, 결과를 받은 바 없다.**
아래는 전부 **flight02 ulog 분석으로 확정·배제된 것**이며 새로운 실측이 아니다.
점검 절차(§2-4)는 제안 상태로만 남는다.

### 2-2. 확정된 것 — FC 지령은 정상이었다

`142150a` 재현검증 기준:

| 항목 | 실측 | 뜻 |
|---|---|---|
| AUX out4 (pusher PWM) | 평균 **1867.9** / 최대 **1900** | 거의 풀스로틀. **FC→ESC 신호는 정상 출력** |
| `VT_F_TRANS_THR` / `VT_PSHER_SLEW` | 1.0 / 1.0 (per s) | 1초에 100% 지령 도달 설정 |
| 실제 지면속도 | 3.4초간 **2.4 m/s** 정착 | 전진 추력이 실효적으로 발생하지 않았다 |

⇒ 문제는 **ESC 이후 구간**이다.

### 2-3. 배제된 것

| 가설 | 배제 근거 |
|---|---|
| **프롭 앞뒤 뒤집힘** | 역방향이어도 공기는 물어 전류가 수십 A 로 오른다. 전류가 안 올랐으므로 배제 (`142150a`) |
| **pusher 부하 회전** | MC 부하를 통제한 대조: MC 4모터 지령 평균 0.722(호버) vs 0.726(천이)로 동일한데 pusher 를 0→100% 로 올려도 전류 **22.21 → 22.06 A 불변**. 전류계 둔감도 아님 — 같은 로그 상승구간 MC 지령 0.847/0.896 에서 31.35/32.03 A 로 따라 오른다 |
| 초판의 "+0.81 A" 근거 | **구간 선택의 산물**로 판명돼 폐기됨. 같은 로그에서 구간을 달리 자르면 −0.20 A 도 +2.1 A 도 나온다 (`142150a` 가 교체) |

### 2-4. 남은 후보와 점검 절차 (제안, 미수행)

로그로는 **더 좁힐 수 없다.** 무부하 회전(1~3 A)은 배터리 전류 노이즈 ±2 A 에 묻혀
**"안 돌았다"와 "돌았지만 공기를 안 물었다"를 가르지 못한다.** 물리 점검만이 이를 가른다.

남은 후보: **미전개(폴딩)·이탈·허브 슬립·피치 소실**

| 단계 | 내용 | 가르는 것 |
|---|---|---|
| A | 프롭 육안·손 점검 — 폴딩 전개 여부, 힌지 걸림, **허브 고정 너트 풀림**(프롭을 잡고 모터축에 대해 돌아가는지), 블레이드 손상·변형 | 허브 슬립이 현재 최유력 후보 |
| B | 전원 차단 상태에서 모터축 수동 회전 — 걸림·긁힘·유격, 다른 모터와 코깅 비교 | 모터 기계 이상 |
| C | ESC·배선 — 3선 체결, 신호선(AUX4) 연결, 발열·탄내·부풀음 | 전기 경로 |
| D | **프롭 제거 후** 저스로틀 통전 — 회전 여부, ESC 비프음 | **ESC/모터 vs 프롭** 을 최종적으로 가름 |

⚠️ D 단계는 프롭을 반드시 제거하고 수행한다.

## 3. 이 문서가 바꾸는 것

- `5d55b3f` 가 "헤딩 의존"으로 규명한 자기계 결함의 **메커니즘이 \|B\| 세기 저하로 특정**됐고,
  **비행 전 지상에서 검출 가능**함이 확인됐다(종전에는 비행 후 ulog 사후분석으로만 알 수 있었다).
- 다만 **야외 GPS fix 없이는 확정 불가**하며, 실내 측정은 외부 왜곡과 분리되지 않는다.
- pusher 는 **로그 분석이 도달할 수 있는 한계에 이미 도달**했다. 진전은 물리 점검에서만 나온다.
