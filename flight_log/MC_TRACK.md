# MC 트랙 (Multicopter) 비행시험 기록

## 개요

- **목적**: 오프보드(Offboard) 코드 검증
- **배경**: 기존에 물리적으로 해체(파손)되었던 MC 테스트기체를 재조립하여 부활시킴. 오프보드 코드 문제를 정확히 짚어내기 위한 별도 검증 플랫폼으로 운용.
- 이제부터 MC 테스트기체와 VTOL 테스트기체가 병행 운용된다 → [VTOL_TRACK.md](./VTOL_TRACK.md)

## 기체 상태

| 항목        | 내용                                     |
| ----------- | ---------------------------------------- |
| 기체 구분   | MC (Multicopter) 테스트기체              |
