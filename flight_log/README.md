# flight_log

실제 기체(MC/VTOL) 비행시험 결과를 기록하는 디렉터리.

## 구성

- [`MC_TRACK.md`](./MC_TRACK.md) — MC(멀티콥터) 테스트기체 상태 및 비행 로그
- [`VTOL_TRACK.md`](./VTOL_TRACK.md) — VTOL 테스트기체 상태 및 비행 로그

## 배경

오프보드(Offboard) 코드 문제를 정확히 짚어내기 위해, 기존에 물리적으로 해체되었던 MC 테스트기체를 부활시켜
VTOL 테스트기체와 병행 운용한다. 두 기체에서 동일 사안을 교차검증하며 원인을 특정한다.

비행결과는 각 트랙 문서의 비행 로그 표에 기록한다.
