## 1. 기존 설계가 왜 성립하지 않았는가 — 자유도 예산

`eta3clothoid_v3_1_planner._solve_g2_nr` 은 전역 결합 잔차계다.

| | 개수 |
|---|---|
| 미지수 | 내부 θ (N−2) + 내부 κ (N−2) + 세그먼트 길이 (N−1) = **3N−5** |
| 방정식 | 세그먼트마다 (Δx, Δy, Δθ) = **3(N−1) = 3N−3** |
| 차이 | **정확히 2개 과결정 — 항상** |

N 과 무관하게 2개 과결정이므로 **정확해가 존재하지 않는다.** `|F| < tol` 은 원리적
도달 불가고(실측 |F| 는 11.6303 에서 정지), affine 보정이 WP 통과만 살려낸 뒤
조인트마다 접선이 꺾인다. `_insert_wps_if_infeasible` 은 판정식
`k_need = 2Δθ/chord` 를 **바꾸지 못하면서**(중점을 넣으면 Δθ 와 chord 가 함께
반이 되어 불변) 삽입점을 폴리라인 **위에** 놓아 경로를 폴리라인에 못박는다.

근본 원인은 **세그먼트당 clothoid 1개(κ 선형)의 자유도가 길이 L 하나뿐인데
양 끝 (θ, κ) 4개 + 위치 2개를 맞추라고 요구받은 것**이다.

## 2. 안 C 제안의 검증 — 무엇을 받아들이고 무엇을 고쳤나

직전 세션 제안: *"세그먼트당 clothoid 2~3조각 + WP 에서 κ=0 → 세그먼트별 3변수
뉴턴, O(N), 진짜 G2, 새 의존 없음"*.

| 제안 | 판정 | 근거 |
|---|---|---|
| WP 에서 κ=0 | **채택** (조건부) | 대칭 코너에서는 **최적**임을 증명(§2.1). 동방향 연속 선회에서는 실측 1.37~1.46배 손해(§2.2) |
| 세그먼트별 분리 → O(N) | **채택** | κ=0 이 경계조건을 이웃과 끊는다. 전역 뉴턴 소멸 |
| clothoid **2조각** | **기각** | 예산은 맞지만(2n−1=3) **κ 부호가 안 바뀌어 S자를 못 만든다**. L자 첫 세그먼트가 정확히 이 경우(§2.3) |
| clothoid **3조각** | **기각** | 자유도 5 대 방정식 3 → 이번엔 2개 **부족**결정. 임의 조건이 또 필요해진다 |
| **3변수** 뉴턴 | **1변수로 축소** | 현 방향으로 회전시키면 방정식이 삼각화된다(§3) |

### 2.1 WP 에서 κ=0 은 대칭 코너에서 최적이다 (증명)

L자·직사각처럼 코너 이등분선에 대해 문제가 대칭이면(양쪽 다리 길이 같음,
양 끝 κ=0), 반사 사상은 해집합을 자기 자신으로 옮기면서 **κ 의 부호를 뒤집는다**.
min-max |κ| 최적해가 대칭이면 코너에서 κ = −κ ⇒ **κ=0**. 즉 이번 대회 경로
(직사각/L자)에서 κ=0 강제는 손해가 아니라 **정답**이다.

### 2.2 대가: 같은 방향으로 계속 도는 WP 열

반지름 R 원 위 등간격 WP 를 지나는 이상적 경로는 κ≡1/R 인데, WP 마다 κ=0 을
강요하면 세그먼트마다 0→peak→0 이 되어

```
peak = 1.5·Δθ / L = 1.5·Δθ / (R·Δθ) = 1.5 / R      (WP 간격과 무관한 상수배)
```

**실측** (`compare_path_quality.py --kappa-zero-penalty`):

| R (m) | WP 수 | 이상 κ | 실측 \|κ\|max | 배수 |
|---|---|---|---|---|
| 200 | 7 | 0.005000 | 0.006867 | **1.373** |
| 200 | 13 | 0.005000 | 0.007317 | **1.463** |
| 400 | 7 | 0.002500 | 0.003434 | **1.374** |
| 150 | 9 | 0.006667 | 0.009178 | **1.377** |

유도값 1.5 배보다 조금 낮은 건 폴리시(§3)가 깎아낸 몫이다.
**동방향 선회가 많은 경로가 오면 내부 κ 자유화가 필요하다** — 2단계 후보.

### 2.3 왜 S자가 필연인가 (2조각 clothoid 가 안 되는 이유)

κ 부호가 일정하면 θ(s) 가 단조라, 현 방향 φ 가 반드시 두 끝 헤딩 **사이**에
있어야 한다. 그런데 첫 세그먼트는 θ₀ = φ₀ (기체가 첫 구간 방향으로 진입)라
경계에 걸린다. L자 3WP:

```
θ₀ = 0°, φ₀ = 0°, θ₁ = 45°,  끝점은 현 위 (200, 0)
⇒ ∫ sin θ ds = 0 인데 θ 가 0→45° 로 단조면 적분이 양수  ⇒ 모순
```

즉 **경로는 코너 전에 반드시 현 아래로 내려갔다가 올라와야 한다**(실측 dip 34.5 m).
단조 κ 로는 표현 불가 → 부호가 바뀌는 곡률 프로파일이 **필수**다.

## 3. 채택한 설계 — 다항 곡률 스파이럴 + 세그먼트당 1변수 뉴턴

세그먼트 k 의 국소 헤딩을 σ = s/L 의 다항으로 둔다.

```
ψ(σ) = α + Δθ·H(σ) + Σ_j c_j · Q(σ)·T(σ)^j
   H = 3σ² − 2σ³        (H(0)=0, H(1)=1)      ← Δθ 를 닫힌형으로 흡수
   Q = σ²(1−σ)²         (Q(0)=Q(1)=0, Q′(0)=Q′(1)=0)
   T = 2σ − 1
   α = θ_k − φ_k        (현 방향 대비 시작 헤딩)
κ(σ) = ψ′(σ) / L
```

`Q` 인자 덕분에 **어떤 c 를 넣어도** κ(0)=κ(L)=0 이 유지되고 총 선회량이 Δθ 로
보존된다. 즉 c 는 순수 "형상" 자유도다.

### 자유도 예산 (요구사항: 방정식 수 = 미지수 수)

| | 기존 eta3 | **안 C (본 설계, 최소형)** |
|---|---|---|
| 미지수 | 3N−5 (전역 결합) | 세그먼트마다 **2** (c₀, L) |
| 방정식 | 3N−3 | 세그먼트마다 **2** (Δx, Δy) |
| 차이 | **+2 과결정 (해 없음)** | **0 — 정확해 존재** |
| 결합 | 전역 (N×N 야코비안) | **없음 — 세그먼트끼리 독립** |

Δθ 는 방정식이 아니라 기저가 구조적으로 보장하므로 방정식에서 빠진다.

### 삼각화 — 3변수가 아니라 1변수다

세그먼트를 현 방향으로 회전시키면 끝점 조건이 (Δx, Δy) = (D, 0) 이 되어

```
S(c₀) ≡ ∫₀¹ sin ψ dσ = 0      ← c₀ 만의 스칼라 방정식 (해석 야코비안 ∂S/∂c₀ = ∫Q cos ψ dσ)
L      = D / ∫₀¹ cos ψ dσ      ← 닫힌형
```

**세그먼트당 1변수 보호 뉴턴, 3~6회 수렴.** 실패하면 확장 브래킷 + 이분으로
폴백하고, 그래도 안 되면 `ok=False` + 사유 문자열로 **보고한다**.
`_solve_g2_nr` 의 정체 판정·clip 재시도·희소 야코비안이 통째로 불필요해졌다
(`15f7fa4` 의 최적화는 전역 뉴턴을 전제한 것이라 이식 대상이 아니다 —
가져온 것은 "결과에 영향 없는 반복을 태우지 말 것"이라는 원칙 쪽이다).

### 폴리시 (선택, 기본 켜짐)

c₁, c₂ 를 더 열면 부족결정이 되고, 남는 자유도를 min-max |κ| 로 쓴다.
c₀ 는 매 후보마다 다시 풀어 Δy=0 을 유지하므로 **WP 통과는 항상 정확**하다.
정사각 해에서 출발해 **개선될 때만 채택**하므로 견고성을 잃지 않는다.

| 세그먼트 (α, Δθ, D) | dof=0 | dof=1 | **dof=2 (기본)** | dof=3 | G1 이론하한 |
|---|---|---|---|---|---|
| 끝세그 (0°, 45°, 200 m) | 1.843 | 1.801 | **1.422** | 1.416 | 1.133 |
| 끝세그 (0°, 45°, 400 m) | 0.922 | 0.900 | **0.711** | 0.708 | 0.566 |
| 중간세그 (−45°, 90°, 200 m) | 1.306 | 1.070 | **1.070** | 1.002 | — (주) |

(단위: ×κmax. 주 — G1 하한 공식은 α=0 인 끝 세그먼트에만 유효하다. §4)
dof=2→3 의 이득이 0.5% 미만이라 **기본값을 2 로 잡았다** — ansatz 는 이미

## 4. 해의 존재 조건 — 그리고 존재하지 않을 때

### 4.1 기하 해의 존재
`S(c₀)=0` 의 근. 실용 영역에서 거의 항상 존재하며, 없으면 `ok=False` + 사유로
보고한다. **조용히 근사해를 돌려주는 경로는 코드에 없다.**

### 4.2 곡률 한계의 만족 — 이론 하한

"WP 정확 통과 + G2 + |κ|≤κmax" 셋이 동시에 되는지는 플래너 실력이 아니라
기하학이 정한다. 되돌지 않는(loop 없는) 경로의 이론 하한을 Pontryagin 으로 얻는다:

> 최대화 ∫cos θ ds  s.t. ∫sin θ ds = 0, θ(0)=0, θ(L)=δ, |θ′|≤k, L 자유.
> 종단시각 자유 ⇒ H ≡ 0. 특이(직선) 호는 H=0 과 모순이라 **존재하지 않는다**
> ⇒ 최적은 순수 bang-bang. α=0 이면 ∫sin θ ds = 0 때문에 θ 가 반드시 한 번
> 음수로 내려가야 하므로 구조는 "−k 로 d 만큼 꺾고 +k 로 되꺾기" **하나뿐**이다.
>
> ```
> cos d = (1 + cos δ)/2 ,      도달 가능 최대 현 = R·[2 sin d + sin δ]
> δ=45° 에서  f = 2 sin(31.400°) + sin 45° = 1.749118
> ```

스위치를 3개로 늘려 수치최적화하면 되돌아 도는 해가 나오는데 그건 현 대비 곡률이
**더 큰** 해라 하한을 바꾸지 못한다(직접 확인: D/R 1.749 → 3.282, 즉 R 이 작아짐).
`curvature_floor_g1()` 로 코드에 들어 있고 테스트가 상수 1.749118 을 잠근다.

**v_cruise=18, a_max_g=0.3, accel_tol=0.85 → κmax = 0.007721 (R_min = 129.5 m)**

| 경로 | G1 이론하한 | 본 플래너(G2) |
|---|---|---|
| A3_L (200 m 다리 90°) | **1.13×** | 1.42× |
| B5_square | **1.26×** | 1.28× |
| S_L30 (30 m 다리 90°) | **7.55×** | 9.43× |

**하한부터 이미 1 을 넘는다.** 곡률 연속(G2)을 포기해도 못 지킨다는 뜻이다.

### 4.3 못 지킬 때 — 무엇을 하는가

`FeasibilityReport` 를 `planner.last_report` 에 남기고 **기본으로 크게 출력**한다.

- 세그먼트별 `|κ|max / κmax`
- `v_feasible = sqrt(a_max / |κ|max)` — **이 기하를 날 수 있는 최대 속도**
- `a_req_g_at_vmin` — `v_min_turn` 으로 날 때 필요한 횡가속(g)
- `speed_floor_violated` — `v_min_turn` 으로도 모자란가
- `decel_margin_m` — 전장 − `decel_dist`(기본 80 m). **짧은 경로 감지**

`speed_policy="curvature"`(기본)이면 `v_ref = min(v_cruise, sqrt(a_max/|κ|))` 를
`v_min_turn` 하한과 함께 내보낸다. `on_infeasible="raise"` 면 예외를 던진다.

숫자로 말한다.** 회귀 테스트가 이 동작을 잠근다.

### 검증 기준 대비

| 지표 | 현재 | 목표 | **달성** |
|---|---|---|---|
| \|κ\|max / 곡률한계 | 161배 | ≤ 1.0 | **1.25~1.42배** — 목표 미달, 그러나 **이론 하한이 1.13~1.26배**라 달성 불가(§4.2) |
| 코너 헤딩 꺾임 | 85.94° | 연속(0) | **0.63°** = κ·ds. 이산화 잔여분뿐 — **연속 달성** |
| WP 통과 오차 | affine 보정으로 강제 | 보정 없이 통과 | **3e-07 m, 보정 코드 없음** ✅ |
| 곡률 연속성(G2) | 미달 | 달성 | **달성** — WP 에서 κ=0 양측 일치, Δκ_max 0.10~0.13×κmax(= κ′·ds) ✅ |
| 계산 시간 | 0.096 / 0.315 s | 악화 없을 것 | **0.024 / 0.058 s — 4~5배 개선** ✅ |

## 6. 🔴 사용자 판단이 필요한 갈림길

곡률 한계를 못 지킨다는 것이 기하학적 사실이므로, **셋 중 하나를 골라야 한다.**
프로토타입에는 (A) 만 구현했고 (B) 는 일부러 구현하지 않았다.

### (A) 코너에서 감속 — 지금 구현된 기본값
경로 기하는 그대로 두고 `v_ref = min(v_cruise, sqrt(a_max/|κ|))` 를 내보낸다.

| 경로 | 필요 속도 v_feasible | v_min_turn(16.5) 로 날 때 필요한 횡가속 |
|---|---|---|
| A3_L | 15.09 m/s | **0.305 g** (a_max_g 0.3 를 넘음, 여유 0) |
| R2_closed | 16.11 m/s | 0.267 g |
| B5_square | 15.90 m/s | 0.275 g |
| B4_uturn | 14.07 m/s | **0.351 g** |

- 장점: WP 를 정확히 통과. 하류 `compute_speed_profile` 이 이미 같은 식을 쓴다.
- 단점: **`v_min_turn=16.5` 하한과 충돌한다.** A3_L 은 16.5 로 날면 0.305 g 가
  필요해 `a_max_g=0.3` 을 살짝 넘고, 15.09 로 내리려면 `v_min_turn` 을 깨야 한다.
  즉 A 만으로는 완전히 해결되지 않는다.

### (B) WP 통과를 포기하고 코너를 자른다 (미구현)
전형적인 fly-by 웨이포인트. 90° 코너에서 R_min=129.5 m 필렛이면
**WP 를 53.65 m 빗나가고**, 코너 양쪽으로 129.5 m 의 접선 여유가 필요하다.
- A3_L(다리 200 m): 접선 129.5 m < 200 m → **들어간다**. |κ| = κmax 정확히 1.0.
- R2_closed(다리 200 m 를 두 코너가 나눠 씀 → 각 100 m): 129.5 m > 100 m →
  **안 들어간다.** 필렛 반경은 R ≤ 100 m 로 줄고 |κ| ≥ **1.30×κmax** 가 된다.
  → **지금 설계(1.25×)보다 오히려 나쁘다.** WP 를 밟는 경로가 더 길어서 더
  완만하게 돌 수 있기 때문이다.
- 판단 포인트: 대회 채점이 WP 통과를 요구하는가? 지오펜스가 바깥 부풀림(최대
  57.6 m)을 허용하는가? **바깥으로 57 m 부푸는 것과 안쪽으로 54 m 자르는 것 중
  어느 쪽이 나은가는 미션 요건이지 수학이 아니다.**

### (C) `a_max_g` 상향
`a_max_g=0.3` 은 뱅크각 16.7° 에 해당한다(구조 한계 `phi_max_deg=69.7` 은 2.7 g).
즉 0.3 은 물리 한계가 아니라 **운용/여유 선택**이다.
- v_cruise=18 을 유지한 채 각 경로를 그대로 실현하려면 (accel_tol=0.85 유지 기준):

  | 경로 | 18 m/s 에서 실제 필요 횡가속 | 필요한 `a_max_g` |
  |---|---|---|
  | R2_closed | 0.318 g | 0.375 |
  | B5_square | 0.327 g | 0.385 |
  | A3_L | 0.363 g | **0.427** (뱅크 23.1°) |
  | B4_uturn (135°) | 0.418 g | 0.491 (뱅크 26.2°) |

- `a_max_g=0.43` 이면 뱅크 23.1° — 구조 한계 69.7° 대비 여전히 매우 여유롭다.
  가장 값싼 해법이지만 실기체 여유(추력·실속 마진·자동조종 튜닝) 판단은 사용자 몫이다.

> **참고 (기하학적 추론 — SITL 실측 아님): 지금 이탈량은 "새로 생기는" 것이
> 아닐 가능성이 높다.** 현재 플래너가 폴리라인(이탈 0.15 m)을 내도 기체는
> a_max_g=0.3, 18 m/s 에서 R=110 m 보다 급하게 돌 수 없으므로 90° 코너를
> 안쪽으로 R(√2−1) ≈ 45.6 m 자르게 된다 — **계획에 없는 추종 오차로**.
> 새 설계는 그 이탈을 바깥 부풀림으로 옮기고 **계획 안에** 넣는다.
> 다만 실제 추종 오차는 L1 유도 이득·바람에 달렸으므로 이 45.6 m 는 계산값이지
> 측정값이 아니다. 2단계 SITL 에서 확인할 것.

## 7. 2단계 (오케스트레이터 지시 대기)

1. **정책 결정 반영** — §6 에서 A/B/C 중 선택. B 를 고르면 `policy="relax"`
   (WP 허용 오차를 받아 코너 컷) 구현이 추가된다.
2. **통합** — `fc_bridge/planning/planner_runner.py` 의 `"eta3"` 를 교체할지,
   새 이름으로 추가하고 파라미터로 고를지. `fc_ros_params.yaml` 의 `planner`.
3. **SITL 전면 재검증** — 경로 형상이 근본적으로 바뀌므로 L1 유도·속도 프로필·
   WP 도달 판정(`d_end_thresh`, `mc_end_thresh`)이 전부 영향권이다.
   특히 **경로가 20~30% 길어진다**(A3_L 400→432 m, 폐회로 800→896 m) —
   타임아웃·배터리 예산 재확인 필요.
4. **내부 κ 자유화** — §2.2 의 1.37~1.46배 손해 제거. 동방향 연속 선회 경로가
   실제로 쓰일 때만 가치가 있다.
5. `RPi5` 실측 — 계산 시간이 노트북 기준 0.058 s 이므로 `planner_eta_s` 의
   코너당 90 s 예고는 이제 3자리 과대예고다(그 함수 주석에 이미 기록됨).
