# mc-실기체 이상현상 — 열린 가설 목록

> **이 문서의 목적:** "비행 → 로그수집 → 분석 → 평가 → 비행" 사이클을 반복할 때마다
> 가설공간을 처음부터 다시 만들지 않기 위한 것. 새 비행을 `analyze_flight.py`로
> 분석한 뒤, 그 결과를 아래 가설들과 대조해서 **상태(status)만 갱신**한다.
> 상세 수치·타임라인은 여기 옮겨적지 않고 해당 flight의 `notes.md`/`analysis_auto.md`를
> 인용한다 — 이 문서는 "지금 뭘 믿고 뭘 안 믿는지"의 요약만 유지한다.
>
> **갱신 절차:** ① 새 분석 결과가 어떤 가설을 지지/반증하면 그 행의 상태·근거를
> 한 줄로 갱신 ② 완전히 새로운 원인후보가 떠오르면 새 행 추가(카테고리 A~D 중
> 적절한 곳에) ③ 상태가 바뀐 것만 아래 "이력"에 한 줄 추가.

## 현상 요약 (반복 관찰된, 변하지 않는 사실 — 상세는 각 flight notes.md)

- 이함(liftoff) 직후 우측으로 roll하는 경향이 여러 비행에서 반복 관찰됨
  (flight02/flight03/수동 log_28/log_29 — 표본 작음, "항상"까지는 확정 못 함)
- flight03에서: 이함(`ground_contact`→0) 약 1.3초 뒤(t≈3.6s) 롤레이트가 잡음수준
  (±5~8deg/s)에서 갑자기 튐 — 이 순간 요구토크는 작고 얼로케이터 포화도 없었음
- 얼로케이터(`unallocated_torque[0]`)는 roll 오차가 27~33도를 넘기 전까진 두 비행
  모두 전혀 포화되지 않음 → **포화 자체는 원인이 아니라 오차가 커진 뒤의 결과**
  (이전에 "포화=하드웨어 이상 증거"로 봤던 것은 정정됨, `docs/session_log.md`
  2026-07-21 항목 참조)
- 같은 세션 배터리는 매 비행 부하중 8.5~9.8V까지 붕괴(3S 휴지전압 11.1~11.9V)
- 목표고도 미달(추력부족)도 같은 세션 내 반복 관찰
