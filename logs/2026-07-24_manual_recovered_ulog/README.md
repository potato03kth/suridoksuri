# 2026-07-24 수동회수 ulog (세션↔파일 정확매칭 불가)

RPi5 tailscale 단절 중 사용자가 FC에서 SD/수동으로 회수해 F:\log\2026-07-24 → E:\Downloads
경유로 이관해준 ulog 8개. 파일명(`HH_MM_SS.ulg`)이 RPi5 rosbag/launch.log가 기록한 실제
ARM 요청 시각(예: flight03 09:25:36 UTC, flight05 09:28:04 UTC)과 맞지 않음 — FC 부팅 시
GPS 미동기 상태의 클록으로 명명된 것으로 추정(`pyulog` `start_timestamp`도 1970년대 근처로
찍혀 GPS 미동기 확인됨). 그래서 각 flightNN 폴더의 rosbag/launch.log와 이 폴더의 특정 ulog를
1:1로 확정 대응시키지 못해 각 flightNN 폴더에서 이쪽으로 빼놓음.

**내용상 정황 매칭(위치값 대조로 유력, 확정 아님):**
- `09_25_37.ulg` ↔ `2026-07-24_flight03`으로 추정 — STREAMING 진입 위치가 flight03
  launch.log의 `pos=[-2.1,-1.3]`와 근사(N=-2.1~-2.8, E=-1.1~-1.5).
- `09_28_05.ulg` ↔ `2026-07-24_flight05`으로 추정 — 마찬가지로 `pos=[-4.7,-2.6]`와 근사
  (N=-4.6~-4.8, E=-2.4~-2.7).
- 나머지(`08_42_22`·`08_47_32`·`08_47_36`·`09_12_16`·`09_25_21`·`09_27_27`)는 flight01·02·04
  (모두 ARM 실패, armed=False 유지)에 대응될 것으로 추정되나 검증 안 함 — 굳이 필요할 정도로
  중요한 데이터는 아님(ARM도 안 됐던 시도들).

각 flightNN 폴더의 결정적 근거는 이 ulog가 아니라 **rosbag+launch.log**(RPi5가 직접 기록,
시각 신뢰 가능)다. 이 폴더는 참고용 보존일 뿐 분석 근거로 인용하지 말 것.
